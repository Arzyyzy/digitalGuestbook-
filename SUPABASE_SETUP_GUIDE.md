# Setup Guide: Digital Guestbook Cloud Storage (Supabase)\n\n> **🔴 PENTING**: Panduan ini HARUS diikuti untuk mengaktifkan penyimpanan data ke cloud. Tanpa setup ini, pesan akan disimpan lokal saja dan tidak sinkron antar device.\n\n## Persyaratan\n- Akun Supabase (gratis di https://supabase.com)\n- Access ke Supabase Dashboard\n- Akses ke project yang sudah dibuat\n\n---\n\n## Step 1: Buka SQL Editor di Supabase\n\n1. Masuk ke https://app.supabase.com\n2. Pilih project Anda\n3. Di sidebar kiri, klik **SQL Editor**\n4. Klik tombol **+ New Query**\n\n---\n\n## Step 2: Jalankan Setup SQL Script\n\n1. Buka file [SUPABASE_SETUP.sql](./SUPABASE_SETUP.sql) di repository ini\n2. Copy **seluruh isi file**\n3. Paste ke SQL Editor di Supabase\n4. Klik tombol **Run** (atau tekan `Ctrl+Enter`)\n\n✅ Jika berhasil, Anda akan melihat output:\n```\n-- Output: QUERY EXECUTED SUCCESSFULLY\n```\n\n❌ Jika ada error, lihat troubleshooting di bawah.\n\n---\n\n## Step 3: Verifikasi Tabel Sudah Dibuat\n\n1. Di sidebar kiri Supabase, klik **Table Editor**\n2. Pastikan Anda melihat tiga tabel baru:\n   - ✅ `guest_messages` — Menyimpan ucapan tamu\n   - ✅ `message_queue` — Queue untuk sinkronisasi offline\n   - ✅ `device_sessions` — Track perangkat aktif\n\n3. Klik `guest_messages` dan verifikasi columns:\n   - `id` (uuid)\n   - `event_id` (text)\n   - `guest_name` (text)\n   - `message` (text)\n   - `drawing_data` (jsonb)\n   - `image_url` (text)\n   - `created_at` (timestamptz)\n   - `deleted_at` (timestamptz)\n   - `device_id` (text)\n   - `metadata` (jsonb)\n\n---\n\n## Step 4: Aktifkan Realtime\n\n1. Di Supabase Dashboard, klik **Database** → **Replication**\n2. Cari section \"Publication: supabase_realtime\"\n3. Toggle **ON** untuk tabel berikut:\n   - ✅ `guest_messages`\n   - ✅ `message_queue`\n   - ✅ `device_sessions`\n\n4. Klik **Save**\n\n> ⚠️ Jika toggle tidak terlihat, scroll ke bawah atau refresh halaman.\n\n---\n\n## Step 5: Verifikasi RLS Policies\n\n1. Klik tabel **guest_messages**\n2. Klik tab **Authentication** → **Policies**\n3. Pastikan Anda melihat 4 policies:\n   - ✅ `allow_public_insert` — INSERT allowed\n   - ✅ `allow_public_read` — SELECT allowed\n   - ✅ `allow_public_update` — UPDATE allowed\n   - ✅ `allow_public_delete` — DELETE allowed\n\nSemua policy harus **ENABLED** (checkbox tercentang).\n\n> 💡 Jika tidak ada policies, script setup mungkin gagal. Ulangi **Step 2** dan pastikan \"QUERY EXECUTED SUCCESSFULLY\" muncul.\n\n---\n\n## Step 6: Test Connection dari Aplikasi\n\n1. Buka aplikasi Digital Guestbook di browser\n2. Lihat **Developer Console** (F12 → Console tab)\n3. Cari logs berikut:\n   ```\n   [Supabase Init] Connecting to: qknmjfvvzmiswyjdfxuq.supabase.co\n   [Supabase] Connection established. Session: none\n   ```\n\n✅ Jika logs muncul = Koneksi berhasil!\n\n4. Buka halaman **Guestbook Kiosk** dan submit sebuah pesan\n5. Kembali ke Supabase Dashboard → **Table Editor** → **guest_messages**\n6. Refresh table (F5 atau tombol refresh)\n7. **Pastikan pesan muncul** di table\n\n---\n\n## Troubleshooting\n\n### ❌ Error: \"column ... does not exist\"\n**Penyebab**: Tabel belum dibuat.\n**Solusi**: \n1. Ulangi Step 2\n2. Pastikan SELURUH isi SUPABASE_SETUP.sql di-copy\n3. Cek bahwa \"QUERY EXECUTED SUCCESSFULLY\" muncul\n\n### ❌ Error: \"permission denied\"\n**Penyebab**: RLS policies tidak aktif.\n**Solusi**:\n1. Buka Database → Policies\n2. Pastikan semua 4 policies pada `guest_messages` **ENABLED**\n3. Klik policies satu-satu untuk verify\n\n### ❌ Pesan tidak muncul di admin dashboard (realtime tidak jalan)\n**Penyebab**: Realtime belum di-enable.\n**Solusi**: Ulangi **Step 4** dan pastikan toggle untuk tiga tabel sudah ON.\n\n### ❌ Console error: \"401 Unauthorized\"\n**Penyebab**: Environment variable `VITE_SUPABASE_ANON_KEY` salah atau hilang.\n**Solusi**:\n1. Buka `.env` file di root project\n2. Pastikan 4 variable ada:\n   ```\n   VITE_SUPABASE_URL=https://[PROJECT_ID].supabase.co\n   VITE_SUPABASE_ANON_KEY=eyJhbGc...\n   VITE_CLOUDINARY_CLOUD_NAME=your_cloud\n   VITE_CLOUDINARY_UPLOAD_PRESET=your_preset\n   ```\n3. Ambil nilai dari Supabase Dashboard:\n   - Settings → API → Project URL & anon key\n\n### ❌ Pesan hilang saat browser di-refresh\n**Penyebab**: Aplikasi masih menggunakan localStorage, bukan Supabase.\n**Solusi**:\n1. Clear browser cache/storage: DevTools → Application → Storage → Clear Site Data\n2. Refresh halaman\n3. Submit pesan baru\n4. Refresh halaman lagi\n5. Pesan harus masih ada ✅\n\n---\n\n## Fitur yang Sekarang Aktif\n\n✅ **Cloud Storage**: Semua pesan tersimpan di Supabase (cloud)\n✅ **Realtime Sync**: Admin dashboard update otomatis saat ada pesan baru\n✅ **Offline Support**: Jika internet putus, pesan disimpan lokal & auto-sync saat online\n✅ **Multi-Device**: Pesan terlihat sama di semua device/akun Google\n✅ **Persistent Data**: Pesan tidak hilang saat refresh browser\n✅ **Admin Monitoring**: Lihat semua pesan masuk realtime di admin panel\n\n---\n\n## Next Steps\n\n### Untuk Pemilik Acara:\n1. **Buka Admin Dashboard**: Tap 5x di bottom-left kiosk\n2. **Pantau Pesan Realtime**: Pesan baru muncul otomatis tanpa refresh\n3. **Filter & Cari**: Gunakan search box untuk cari nama tamu\n4. **Hapus Pesan**: Klik delete untuk hapus pesan tertentu\n\n### Untuk Developer:\n1. **Custom Realtime Logic**: Lihat `subscribeToMessagesRealtimeAdmin()` di `src/lib/supabaseMessages.ts`\n2. **Offline Queue Config**: Edit constants di `src/lib/offlineQueue.ts`\n   - `MAX_RETRIES = 5`\n   - `MAX_QUEUE_SIZE = 100`\n   - `TTL_MS = 24 hours`\n3. **Add Drawing Replay**: Drawing data tersimpan di `drawing_data` JSONB column\n\n---\n\n## Support\n\n**Masalah?** Cek:\n1. ✅ Apakah Step 1-4 sudah selesai?\n2. ✅ Apakah \"QUERY EXECUTED SUCCESSFULLY\" terlihat?\n3. ✅ Apakah Realtime toggle sudah ON?\n4. ✅ Apakah RLS policies semua ENABLED?\n5. ✅ Cek browser console (F12) untuk error messages\n\nJika masih tidak bisa, kontakkan developer dengan screenshot error di console.\n\n---\n\n**Last Updated**: May 2026\n**Version**: 1.0\n"}
